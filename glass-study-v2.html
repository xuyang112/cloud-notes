Python类型入门

Python 是一门解释型、动态类型的高级语言。变量不需要声明类型，赋值即创建，这一点与 Java、C 的差异很大。

类型判断

判断类型时推荐使用 isinstance()，它会考虑继承关系，比直接比较 type() 更安全。

def check(value): # isinstance 会考虑继承关系 if isinstance(value, int): return "整数" return "其他"

字面量写法、运算符优先级与作用域规则，构成了这门语言的骨架。掌握这三者之后再去读标准库，会轻松很多。
