# 云笔记

这是一个无需构建的静态网站。通过 GitHub Pages 发布后，任何持有链接的人都可以在异地打开网站。

## 发布到公网

首次发布由 GitHub Actions 自动完成。站点发布成功后，在仓库的 **Settings > Pages** 中可以看到可分享的公网地址。

之后每次修改 `index.html`、`app.js` 或 `styles.css`，提交并推送到 `main` 分支，GitHub Pages 会自动更新线上网站。也可以在 GitHub Pages 设置中绑定自己的域名。

## 数据说明

目前笔记数据保存于浏览器的 `localStorage`：公网地址可以在任意设备打开，但在某台设备新增、编辑或删除的笔记，不会自动同步到另一台设备。要实现跨设备同步和私密访问，需要再接入云端数据库和登录系统。
